# Auto Click Sell Mod

Minecraft 1.21.1 Forge mod that automatically clicks SELL button in shop/trading GUIs.

## Features

✅ **Auto Click SELL Button** - Automatically clicks SELL button when shop GUI opens
✅ **Auto Confirm** - Automatically confirms sales
✅ **Toggle On/Off** - Press **V** key to toggle mod
✅ **Easy Configuration** - Simple on-screen toggle

## Installation

1. Install **Forge 1.21.1** or higher
2. Download `autoclicksellmod-1.0.0.jar`
3. Place in `mods` folder
4. Launch Minecraft with Forge profile

## Usage

- **Press V key** to toggle Auto Click on/off
- Status appears in top-right corner
- Works with any shop/trading GUI containing SELL button

## Requirements

- Minecraft 1.21.1+
- Forge 54.0.0+
- Java 21+

## Build from Source

```bash
./gradlew build
```

JAR file will be at: `build/libs/autoclicksellmod-1.0.0.jar`
