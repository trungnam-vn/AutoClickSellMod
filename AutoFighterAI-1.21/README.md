# Auto Fighter AI 0.9.6 — Minecraft 1.21

Fabric client mod with the same feature set as the 1.21.5 build:
- Auto PvE combat and nearest-hostile reacquisition
- Movement, obstacle jumping, and dodge movement
- Low-health automatic eating
- Functional GUI toggles and target range adjustment (5–200 blocks)
- Continues AI movement while the vanilla player inventory (E) is open
- Settings saved in `.minecraft/config/autofighterai.properties`

Target: Minecraft Java 1.21, Fabric, Java 21.
